### 💘 SwipeMate — Developer Matchmaking Platform
<sub>`Backend in progress` · `Frontend planned`</sub>

<a href="https://github.com/Hardoo-009/SwipeMate-Backend">
  <img align="right" src="https://github-readme-stats.shion.dev/api/pin/?username=Hardoo-009&repo=SwipeMate-Backend&theme=catppuccin_mocha&hide_border=true" alt="SwipeMate repo card" />
</a>

A developer-centric social networking backend, "matchmaking for developers".

- 🔎 Discovery feed powered by complex **Mongoose queries** and relationship filters
- ⏳ **30-day connection retry cooldown** logic
- 🔐 **HTTP-only JWT** authentication with a **Redis-backed token blacklist** for instant logout invalidation
- ⚡ **Compound MongoDB indexes**, schema-level validation hooks and modular routing for scalable performance
